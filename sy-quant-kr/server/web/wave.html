DISCOVERED → WATCH → READY → TRIGGER → HOLD → PROTECT → SOLD 순서로 진행합니다. READY는 종목·눌림 조건 통과, TRIGGER는 실제 반등을 1차 확인한 상태입니다. TRIGGER 즉시 매수하지 않고 다음 평가에서도 조건이 유지되어야 HOLD로 전환합니다. 보유 후에는 서버의 실제 protectActive·trailingActive 상태를 우선 표시합니다. WAVE 매수·매도 자금은 MASTER 단일계좌에서 처리되고, 후보·사전분석·WATCH 이력은 WAVE 전용 상태로 유지됩니다.
