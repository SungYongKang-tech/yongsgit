# SY퀀트 FAST V1.1.0

FAST는 장 초반 HOT 후보를 5초 단위 원자료로 관찰해 초기급등 구간에 빠르게 진입하는 독립 모의매매 전략입니다.

## 계좌 설정

- 초기 모의자금: 50,000,000원
- 종목당 목표 매수금액: 매일 FAST 기준 총자산의 20%
- 최대 동시 보유: 5종목
- 일일 최대 매수: 5회
- 같은 종목: 하루 1회만 매수
- 신규매수 시간: 09:00~10:30
- 상태 파일: `paper-state-fast.json` 자동 생성

기존 `paper-state.json`, CORE, VOLUME, OPEN, WAVE의 현금·보유·거래기록은 사용하거나 변경하지 않습니다.

FAST는 매일 최초 평가 때 총자산을 `allocationBaseAsset`으로 저장하고 그 금액의 20%를 당일 종목당 매수금액으로 고정합니다. 따라서 초기에는 5천만원의 20%인 1천만원씩, 다음 거래일에는 전일까지의 손익이 반영된 총자산의 20%씩 최대 5종목을 매수합니다. 주식은 정수 수량으로만 살 수 있어 실제 매수 뒤에는 단주 미만의 소액 현금이 남을 수 있습니다.

## 배포 파일

- `fast-strategy.js`: FAST 후보 관찰, 매수·매도, 독립 모의계좌
- `fast.html`: FAST 전용 대시보드
- `server.js`: FAST API와 시세 요청 우선순위 및 자동실행 연결
- `performance.html`: 상단 WAVE 옆 FAST 버튼 추가
- `performance.js`: 현재 대시보드와 한 쌍인 스크립트
- `hot-scanner.js`: FAST가 사용하는 장초반 EARLY 후보·지속강도 자료

같은 서버 폴더에 파일을 덮어쓴 뒤 서버를 재시작합니다. 웹 정적 파일 경로에는 `fast.html`, `performance.html`, `performance.js`가 함께 있어야 합니다.

## API

- `GET /api/fast-summary`: 화면용 FAST 요약
- `GET /api/fast-state`: FAST 전체 상태
- `POST /api/fast-run-once`: 즉시 한 번 평가
- `POST /api/fast-reset`: FAST 계좌만 5천만원으로 초기화

## 진입 원칙

FAST는 단순 등락률 상위 종목을 바로 사지 않습니다. 최초 +1~+7% 구간 포착, 현재 +1.5~+10%, 거래량, 당일 고가 위치, 시가 위, HOT·지속강도, 최소 3회 가격·거래량 지속, 순위/섹터 교차확인, 실시간 시세 3초 이내를 다시 확인합니다.

시장점수 20점 미만은 신규매수를 막습니다. 20~25점 약세장에서는 최소 4회 관찰과 더 높은 HOT·지속강도·교차확인을 요구해 OPEN의 25점 절대차단보다 기회는 넓히되 무조건 추격하지 않게 했습니다.

## 청산 원칙

- 초기손절: -1.0%
- +2% 도달 후 본전보호: +0.3%
- +5% 이후 고점대비 -1.5% 트레일링
- +10% 이후 고점대비 -2.5% 트레일링
- 10분 동안 최고 +0.5% 미만이면 초기정체 청산
- 최고 +2% 미만인 약한 종목은 60분 시간청산
- 15:10 장마감 청산

모든 거래는 모의매매이며 실제 증권 주문 API를 호출하지 않습니다.
