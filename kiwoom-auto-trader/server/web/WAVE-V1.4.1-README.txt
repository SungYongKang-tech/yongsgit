SY Quant WAVE V1.4.1 - 규칙 재평가 보정

문제:
V1.3에서 8/18 야간 사전평가가 이미 완료된 상태에서 V1.4를 배포하면,
같은 날짜라는 이유로 V1.4가 기존 26개 활성 후보를 다시 평가하지 않아
화면에 "야간 사전분석 완료 · 0개 평가"가 나오고 기존 READY 4개가 유지될 수 있었습니다.

수정:
- 분석규칙 버전(ANALYSIS_RULE_VERSION) 도입
- 규칙버전 변경 시 장마감/장전 완료표시 자동 무효화
- 기존 WATCH/READY 전체 새 규칙으로 강제 1회 재평가
- lastAnalysis에 분석규칙 버전 저장
- +10% 이상 당일 급등 READY 금지 규칙을 기존 후보에도 즉시 적용

적용:
1) paper-state-wave.json 삭제 금지
2) wave-strategy.js 교체
3) pm2 restart kiwwm-server
4) 로그에서 [WAVE 야간사전평가] 시도/완료 확인

예상:
씨유메디칼(+15.20%), 삼성공조(+29.92%) -> WATCH
HPSP(+5.57%), 한미반도체(0.00%) -> 다른 조건 유지 시 READY
