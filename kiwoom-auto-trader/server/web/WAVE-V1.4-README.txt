- wave.html

핵심 변경
1. 당일 상승률 +10% 이상 종목은 READY 금지
   - WHY/MONEY/SECTOR/눌림 점수가 높아도 WATCH 유지
   - 다음 거래일부터 상승률이 진정되고 눌림 조건이 유지되면 READY 재평가
2. 기존 READY 종목도 재평가 시 +10% 이상이면 WATCH로 되돌림
3. 실제 WAVE 모의매수의 당일 상승률 상한 +7%는 그대로 유지
4. wave.html 후보 카드에 READY 보류 사유 표시

적용 시 주의
- paper-state-wave.json 삭제 금지
