본사사옥 태양광 발전관리 V2 - 월간 입력 버전

변경사항
1. 매일 입력 기능 제거
2. 매월 1일 검침 기준으로 변경
3. 기본 입력: 누적발전량
   - 이전 누적값 자동 조회
   - 이번 누적값 - 이전 누적값 = 전월 발전량 자동 계산
4. 과거자료 입력용 '월 발전량 직접 입력' 모드 추가
5. 최근 18개월 월별 실적 표시
6. 인버터 화면 사진은 2026년 7월부터 월 3장 유지
7. 입력/수정 비밀번호: 1111

Firebase 저장 경로
- 월간 발전자료: solar/monthly/YYYY-MM
- 월별 사진자료: solar/monthlyPhotos/YYYY-MM
- 사진 파일: solar/inverterPhotos/YYYY-MM/설비ID.확장자

검침월 의미 예시
- 2026-09 검침월 = 2026년 9월 1일 검침값
- 누적발전량 모드에서는 2026-08 월 발전량을 계산함

설비
- 체육관 옥상 B 46.08 kW (상부 좌측)
- 체육관 옥상 A 50.22 kW (상부 우측)
- 강당 옥상 102.4 kW (하부 전체)

주의
비밀번호 1111은 HTML/JS 내부의 간편 잠금입니다. 공개 웹사이트에서 강한 보안이 필요하면 Firebase Authentication으로 변경해야 합니다.
