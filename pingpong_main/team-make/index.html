🏓 KOEN 단체전 생성기 사용법

1️⃣ 선수 등록

  • ➕ 이름과 부수를 입력하고 선수 추가를 누르면 새 선수 등록
  • 🟡 새로 추가된 선수는 노란색으로 표시
  • ✖ 잘못 추가된 선수는 이름 옆 ✖ 버튼으로 개별 삭제 가능
  • 🗑️ 추가 선수 삭제 버튼으로 전체 삭제 가능

2️⃣ 팀 배정

  • 팀 자동 배정: 팀 수 선택 → 인원/부수 평균(낮을수록 강함) 균형 배정
  • 팀 수동 배정: 팀 수 입력 → 참석자 목록에서 버튼으로 직접 배정

3️⃣ 경기 시작

  • 🚀 경기 시작 버튼 클릭 시 Firebase에 팀 정보 저장

⚔️ 교류전 설정

1️⃣ 참가 기관

기존 직원은 자동으로 남동발전 소속입니다. 새로 추가한 선수는 선수 추가 때 입력한 기관으로 자동 분류됩니다.

2️⃣ 기관별 팀 수

예: 남동발전 1팀 + 저작권위원회 1팀 + LH 1팀이면 세 기관이 서로 한 번씩 경기합니다.

3️⃣ 선수 소속 확인

선수 소속을 확인해주세요.
